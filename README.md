 Valery – Loja Virtual de Joias

 Sobre o projeto
O Valery é um sistema de comércio eletrônico desenvolvido como parte do Projeto Integrado Multidisciplinar (PIM IV), do curso de Análise e Desenvolvimento de Sistemas da UNIP.

O objetivo é desenvolver uma plataforma de vendas online de joias, oferecendo aos usuários uma experiência simples e intuitiva para visualizar produtos e realizar compras.

 Funcionalidades
- Cadastro e login de usuários.
- Visualização e consulta de produtos.
- Organização de produtos por categorias.
- Carrinho de compras.
- Gerenciamento de pedidos.
- Área administrativa.

Tecnologias utilizadas
C# com .NET MAUI, ASP.NET Core e MySQL.

Estrutura do projeto
- Web: versão web da plataforma.
- Mobile: versão para dispositivos móveis.
- API: responsável pela comunicação entre os módulos.
- Banco de Dados: armazenamento das informações do sistema.

 Projeto acadêmico
Projeto desenvolvido para o PIM IV – Análise e Desenvolvimento de Sistemas – UNIP.
